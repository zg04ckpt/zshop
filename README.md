# ZShop - Phiên bản thử nghiệm 1.0

## Introduction
ZShop is an online bookstore providing a seamless platform for users to browse, purchase, and review books. With a modern interface and robust features, ZShop ensures a convenient and engaging shopping experience.

> **Note:** All content and data on this website are for testing purposes only and have no real-world value.

**Test Account:** `test@zshop.com` | `test`

## Main Features

### 📚 Quản lý sách (Book Management)
Thêm, sửa, xóa sách với đầy đủ thông tin: tên, tác giả, mô tả, giá, hình ảnh

### 🛒 Giỏ hàng & Thanh toán (Shopping Cart & Payment)
Thêm sách vào giỏ hàng, áp dụng voucher, thanh toán và theo dõi đơn hàng

### 👥 Quản lý người dùng (User Management)
Đăng ký, đăng nhập, quản lý thông tin tài khoản, địa chỉ giao hàng

### ⭐ Đánh giá & Nhận xét (Reviews & Ratings)
Khách hàng có thể đánh giá và nhận xét sách sau khi mua

### 💬 Chat hỗ trợ (Support Chat)
Hệ thống chat trực tuyến giữa khách hàng và admin

### 📊 Quản lý đơn hàng (Order Management)
Cập nhật trạng thái đơn hàng, xem thông tin chi tiết

## Technologies

### Frontend
- **React (TypeScript)** - Thư viện xây dựng giao diện người dùng
- **Redux Toolkit** - Quản lý state toàn cục của ứng dụng
- **Bootstrap 5** - Thư viện CSS để thiết kế responsive + làm đẹp UI
- **Axios** - Cơ sở các phương thức và lớp xử lý giao tiếp với Backend thông qua API
- **React Router** - Điều hướng trang trong ứng dụng
- **CKEditor** - Trình soạn thảo văn bản HTML
- **Font Awesome** - Thư viện icon
- **Material UI** - Thư viện UI cung cấp các component được xây dựng sẵn

### Backend
- **ASP.NET Core (.NET 6)** - Xây dựng ứng dụng cung cấp API phía máy chủ
- **MySQL** - Cơ sở dữ liệu cho website
- **Cloudinary** - Dịch vụ cloud quản lí các dữ liệu media
- **JWT + Cookie** - Cơ chế xác thực và phân quyền users
- **Entity Framework Core** - ORM framework
- **Redis** - Lưu trữ các thông tin truy xuất nhanh
- **SignalR** - Triển khai tính năng Chat hỗ trợ
- **VNPay** - Thanh toán online
- **MailKit** - Hỗ trợ gửi email tự động
- **OAuth (Google)** - Đăng nhập với tài khoản Google
